# 0.1.0 Foundations — test plan

Owner: `[QA]`. Epic [TC-1](https://mathsuch63.atlassian.net/browse/TC-1). Strategy: [test-strategy.md](../process/test-strategy.md).
Status: draft for 0.1.0; updated when a story's acceptance criteria change or when a test lands (add its file/test name).

**Levels:** `Unit` (developer suite in the app/package) · `API` (`tests/api/`, black-box) · `E2E` (`tests/e2e/`,
Playwright-Electron) · `CI` (evidence from a GitHub Actions run) · `Insp` (QA reads a document/file and records the
result) · `Manual` (scripted steps below, run by QA).
**OS:** `W` Windows, `L` Linux, `W+L` both. Automated cases run on both OSes in CI unless noted.
Every case is executed when its story is in **In Test** and again at the beta regression (cases marked **R**).

Manual commands use `<backend-cmd>` for the documented way to start the backend (`uv run …` from TC-17) and
`<app-cmd>` for the documented dev launch of the desktop app (TC-23).

## 3. Manual procedures

**M-24-1 — no leftover backend (Windows; Linux equivalent in brackets).** Run for exit criterion X-5 at every beta.
1. Start `<app-cmd>`; note the backend PID from the app log (or `Get-CimInstance Win32_Process | ? CommandLine -like '*<backend module>*'`
   [`pgrep -af <backend module>`]).
2. Quit from the menu → within 10 s the PID is gone and no matching command line remains.
3. Start again; close the window with the title-bar ✕ → same check.
4. Start again; kill the Electron main process (`Stop-Process -Id <electron main pid> -Force` [`kill -9`]).
   The backend may survive this step — record it. Start the app again → the orphan from the PID file is gone
   within the startup sequence, and only the new backend runs.
5. Record PIDs and timings in the Jira journal / beta report.

**M-EXP — exploratory charter for 0.1.0 (30 min per OS).** Start/quit the app repeatedly and quickly; start with
the port range busy; start two copies; kill the backend at different moments of startup; run from a user profile
path with a space and non-ASCII characters; check that logs contain no token; resize the window and switch OS
theme.

## 4. Out of scope for 0.1.0
Packaged builds and installers (1.0.0), real rlgym-learn runs (0.4.0+), fake runner (0.4.0; requirements in the
strategy §9), migrations (0.2.0).
